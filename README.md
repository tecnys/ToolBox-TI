## 📋 Descripción

**Tecnys ToolBox** es una interfaz gráfica en PowerShell que centraliza todas las utilerías necesarias para el soporte técnico de PCs en Windows. Con un solo comando, puedes descargar instaladores, abrir herramientas de diagnóstico y ejecutar utilidades avanzadas sin buscar en Google.

Diseñado para agilizar el trabajo diario del área de soporte técnico.
